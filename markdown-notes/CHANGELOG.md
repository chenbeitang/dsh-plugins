# 版本说明 · @local/markdown-notes

**当前版本：1.4.0**（2026-11-06）  
**运行环境**：DeepSeek Harness Web GUI（左侧栏面板 + Host HTTP API）  
**入口**：左侧栏「Markdown 笔记」图标（面板 id `markdown-notes`）

本文件记录每个版本的定位、功能变化与已知边界；安装与使用说明见 [README.md](README.md)。

## 版本历史

### 1.4.0 — 可拖动分栏宽度

- 分栏视图中间新增可拖动分割线，拖动即可调整左侧原文 / 右侧预览的宽度。
- 每侧最小宽度约 220px，拖动过程中用 `requestAnimationFrame` 节流；分割线在悬停 / 拖动时高亮。
- 双击分割线恢复 50/50；分割线可聚焦（`role="separator"`），聚焦后左右方向键微调，`Home` 恢复默认。
- 宽度比例写入本地 UI 偏好，刷新后保持；窗口较窄进入上下堆叠布局时自动隐藏分割线。
- 新增 `splitRatio` 偏好字段与分割线相关中英文文案。

### 1.3.1 — 修复引用块（`>`）字符定位错位

- **根因**：渲染器在块与块之间用换行文本节点分隔（如 `</p>\n<ul>`）。`collectRenderedSegments`
  把这些纯空白文本节点误判成空行段，使引用块内 `<p>` / `<ul>` / `<p>` 之间多出空段；
  行号到渲染段的索引整体后移，导致以 `>` 开头的引用块字符定位错位。
- **修复**：忽略纯空白文本节点，只保留 `<br>` 与代码文本中真实的换行空段；引用块行段数量与源码可见行数恢复一一对应。
- 同时处理：
  - DOM Selection 落在元素节点（而非文本节点）时用 `comparePoint` 对齐最近文本字符；
  - 列表项正文以 `>` 或 `#` 开头时，不再被误当成块级标记剥掉（只剥离引用前缀和一个标题/列表标记）；
  - 新增「引用块 + 列表 + 段落」「渲染块之间的空白文本节点」回归测试。

### 1.3.0 — 双端光标与字符级定位

- 新增分栏模式下的**双端光标提示**：一侧获得编辑焦点时，另一侧显示同款闪烁光标，标出当前内容在另一侧的位置。
- 原文侧使用隐藏 mirror 复刻 textarea 字体、宽度与换行，精确测量光标在 textarea 中的坐标。
- 渲染侧引入 `data-line` / `data-line-end` 与「源码字符骨架 → 渲染文本」逐字符对齐：
  - 支持标题、段落（含自动换行）、粗体 / 斜体 / 删除线 / 高亮 / 下划线、行内代码、链接文字、转义字符；
  - 支持有序 / 无序 / 任务列表、引用、代码块、表格单元格；
  - **Markdown 格式标记本身不参与定位**，光标落在标记内时贴到最近的可见字符。
- 表格按「表头 / 数据行 → 单元格 → 单元格内字符」单独映射，双向定位。
- 光标跟随 `selectionchange`、输入、滚动、窗口缩放与面板布局变化；另一侧内容不可见时自动隐藏，避免悬空显示。

### 1.2.0 — 同步滚动

- 标题栏新增「同步滚动」选项（分栏模式可用，状态持久化）。
- 滚动按内容块与行号对齐，而不是简单总高度百分比；顶部 / 底部做边界对齐。
- 用 `requestAnimationFrame` 节流并加回环锁，避免两侧滚动互相触发抖动。
- 切换笔记、切回分栏或启用开关时自动对齐一次。

### 1.1.0 — 图片缩放

- 渲染视图点击图片显示缩放手柄（右侧 / 底部 / 右下角），拖动等比调整宽度，双击恢复原始尺寸。
- 尺寸以 Markdown 扩展属性保存：`![alt](path){width=320}`。
- 原文与渲染双向同步；旧图片（无 `width`）保持原样。
- 支持选中态、尺寸徽标、滚动与面板缩放后的浮层重新对齐。

### 1.0.0 — 首个版本

- 左侧栏入口与 `markdown-notes` 主面板。
- 本地 Markdown 仓库：可配置存储根目录、目录树、新建 / 重命名 / 删除文件夹与笔记。
- 左侧 Markdown 原文 textarea + 右侧渲染 contenteditable，左右两侧均可直接编辑。
- 可选 `分栏 / 原文 / 预览` 三档视图，视图偏好持久化。
- 图片上传（粘贴 / 拖入 / 按钮）、媒体接口渲染、自动保存、Ctrl/Cmd+S、收藏、删除确认、全文搜索。
- Host API、路径越界校验、图片魔数白名单、同源写请求校验。
- Agent 工具 `markdown_notes`（list / read / create / append / write / mkdir / search / favorite / delete / set_storage）。

## 已知边界

- Markdown 格式字符（`#`、`*`、`~`、反引号、列表标记等）在渲染侧没有独立可见字符，光标位于标记内部时会贴到最近的可见字符。
- 图片 alt 文本与链接 URL 在预览中不显示，无法作为定位目标；会在附近文字上兜底。
- 极少数复杂结构（嵌套引用中的表格、HTML 混排、列表续行等）可能退回行级几何近似。
- 渲染视图内新建、尚未带 `data-line` 的段落不会立即具备字符级映射（原文一侧编辑后会重新渲染补齐）。
- 光标提示只在分栏模式生效；另一侧当前滚动位置看不到目标内容时，光标会隐藏。
