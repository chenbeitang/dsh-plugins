# 版本说明 · @local/markdown-notes

**当前版本：1.7.0**（2026-11-06）  
**运行环境**：DeepSeek Harness Web GUI（左侧栏面板 + Host HTTP API）  
**入口**：左侧栏「Markdown 笔记」图标（面板 id `markdown-notes`）

本文件记录每个版本的定位、功能变化与已知边界；安装与使用说明见 [README.md](README.md)。

## 版本历史

### 1.7.0 — 代码块多语言语法高亮

- 围栏代码块按语言标记（` ```java `、` ```xml ` 等）进行语法高亮，不再只以等宽纯文本展示。
- 内置语言支持：
  - Java、JavaScript / TypeScript、Python、C / C++ / C#、Go、Rust、Kotlin / Scala、Swift、PHP、Ruby；
  - SQL、XML / HTML / SVG、CSS / SCSS / LESS、JSON / JSONC、YAML、TOML / INI；
  - Shell / Bash / Zsh、PowerShell、Dockerfile、Makefile、diff / patch。
- 按语言特性区分类别：
  - 关键字、类型、函数、字符串（含三引号 / 模板字符串）、数字、布尔值、注释；
  - XML/HTML 的标签、属性、属性值、实体、CDATA、注释；
  - JSON 的 key / 字符串、布尔、注释（JSONC）；
  - diff 的增删行与 hunk 头。
- 高亮只插入 `<span>`，不改变代码文本；代码块与表格共享深色边框，光标映射、复制、Markdown 回写均保持原有行为。
- 修正高亮把代码拆成多个 span 后，代码中的空格 / 换行在预览字符映射中被误忽略的问题；新增「高亮代码块字符映射」回归测试。
- 围栏语言标记支持 `c#`、`c++`、`objective-c` 等带符号的写法；未知语言退化为通用高亮（注释 / 字符串 / 数字），代码始终经过 HTML 转义。
- 新增 `MN.md.highlightCode` / `resolveLanguage` 纯函数与多语言文本保真、token 分类测试。

### 1.6.2 — 代码块边框与表格统一

- 代码块 `<pre>` 外框改用与表格外框相同的深色边框变量 `--mn-block-border`。
- 表格与代码块共享同一主题感知边框色，避免一个深一个浅。
- 仅样式调整，不改动渲染结构。

### 1.6.1 — 表格边框加深

- 渲染视图中的表格外框、单元格分隔线、表头底边改为从 `label-secondary` 混合出的更深边框色，不再使用接近背景的 `border-l1`。
- 保留宿主主题 token：浅色/深色主题下都会跟随文字色，避免只适配一种主题。
- 表格圆角、背景、单元格内边距不变。

### 1.6.0 — 文件管理器中打开 + 拖动移动

- **从文件管理器中打开**：文件夹 / 笔记的右键菜单和“...”菜单新增入口。
  - Windows：文件通过 `explorer.exe /select,` 打开父目录并选中；文件夹直接打开。
  - macOS：文件 `open -R`（Finder 显示并选中）；文件夹 `open`。
  - Linux：`xdg-open` 打开父目录（文件管理器选中行为尽力而为）。
  - Host 端只接受笔记根目录内的路径，并在打开前校验存在性与是否为符号链接。
- **拖动移动**：树节点可拖拽到非子级文件夹。
  - 目标文件夹高亮；禁止拖到自身、自身子级、当前父目录或已有同名条目的位置。
  - Host 新增 `POST /api/entry/move`，使用 `fs.rename`，同步更新收藏与最近打开路径。
  - 拖动前自动保存当前笔记；活动笔记或其所在文件夹被移动后，客户端路径同步更新。
- 新增 `entry/reveal`、`entry/move` HTTP 路由、`host/reveal.js` 与对应中英文文案。

### 1.5.0 — 可收起文件操作栏

- 文件操作栏（左侧目录树 / 收藏 / 搜索）顶部新增「收起文件栏」按钮。
- 收起后整块文件栏不再渲染，主编辑区自动铺满；左上角保留一个悬浮的「展开文件栏」按钮，再次点击恢复。
- 收起 / 展开状态写入本地 UI 偏好，刷新后保持。
- 收起时主标题区自动让出按钮位置，避免遮挡；空笔记状态同样可展开。
- 新增 `sideCollapsed` 偏好字段与中英文提示文案。

### 1.4.0 — 可拖动分栏宽度

- 分栏视图中间新增可拖动分割线，拖动即可调整左侧原文 / 右侧预览的宽度。
- 每侧最小宽度约 220px，拖动过程中用 `requestAnimationFrame` 节流；分割线在悬停 / 拖动时高亮。
- 双击分割线恢复 50/50；分割线可聚焦（`role="separator"`），聚焦后左右方向键微调，`Home` 恢复默认。
- 宽度比例写入本地 UI 偏好，刷新后保持；窗口较窄进入上下堆叠布局时自动隐藏分割线。
- 新增 `splitRatio` 偏好字段与分割线相关中英文文案。

### 1.3.1 — 修复引用块（`>`）字符定位错位

- **根因**：渲染器在块与块之间用换行文本节点分隔（如 `</p>\n<ul>`）。`collectRenderedSegments`
  把这些纯空白文本节点误判成空行段，使引用块内 `<p>` / `<ul>` / `<p>` 之间多出空段；
  行号到渲染段的索引整体后移，导致以 `>` 开头的引用块字符定位错位。
- **修复**：忽略纯空白文本节点，只保留 `<br>` 与代码文本中真实的换行空段；引用块行段数量与源码可见行数恢复一一对应。
- 同时处理：
  - DOM Selection 落在元素节点（而非文本节点）时用 `comparePoint` 对齐最近文本字符；
  - 列表项正文以 `>` 或 `#` 开头时，不再被误当成块级标记剥掉（只剥离引用前缀和一个标题/列表标记）；
  - 新增「引用块 + 列表 + 段落」「渲染块之间的空白文本节点」回归测试。

### 1.3.0 — 双端光标与字符级定位

- 新增分栏模式下的**双端光标提示**：一侧获得编辑焦点时，另一侧显示同款闪烁光标，标出当前内容在另一侧的位置。
- 原文侧使用隐藏 mirror 复刻 textarea 字体、宽度与换行，精确测量光标在 textarea 中的坐标。
- 渲染侧引入 `data-line` / `data-line-end` 与「源码字符骨架 → 渲染文本」逐字符对齐：
  - 支持标题、段落（含自动换行）、粗体 / 斜体 / 删除线 / 高亮 / 下划线、行内代码、链接文字、转义字符；
  - 支持有序 / 无序 / 任务列表、引用、代码块、表格单元格；
  - **Markdown 格式标记本身不参与定位**，光标落在标记内时贴到最近的可见字符。
- 表格按「表头 / 数据行 → 单元格 → 单元格内字符」单独映射，双向定位。
- 光标跟随 `selectionchange`、输入、滚动、窗口缩放与面板布局变化；另一侧内容不可见时自动隐藏，避免悬空显示。

### 1.2.0 — 同步滚动

- 标题栏新增「同步滚动」选项（分栏模式可用，状态持久化）。
- 滚动按内容块与行号对齐，而不是简单总高度百分比；顶部 / 底部做边界对齐。
- 用 `requestAnimationFrame` 节流并加回环锁，避免两侧滚动互相触发抖动。
- 切换笔记、切回分栏或启用开关时自动对齐一次。

### 1.1.0 — 图片缩放

- 原文与渲染双向同步；旧图片（无 `width`）保持原样。
- 支持选中态、尺寸徽标、滚动与面板缩放后的浮层重新对齐。

## 已知边界

- Markdown 格式字符（`#`、`*`、`~`、反引号、列表标记等）在渲染侧没有独立可见字符，光标位于标记内部时会贴到最近的可见字符。
- 图片 alt 文本与链接 URL 在预览中不显示，无法作为定位目标；会在附近文字上兜底。
- 极少数复杂结构（嵌套引用中的表格、HTML 混排、列表续行等）可能退回行级几何近似。
- 渲染视图内新建、尚未带 `data-line` 的段落不会立即具备字符级映射（原文一侧编辑后会重新渲染补齐）。
- 光标提示只在分栏模式生效；另一侧当前滚动位置看不到目标内容时，光标会隐藏。
