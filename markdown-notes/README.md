# Markdown 笔记（@local/markdown-notes）

当前版本：**1.9.1**（2026-11-06） · [版本说明 / 更新日志](CHANGELOG.md)

DSH Web UI 左侧栏里的本地 Markdown 笔记管理器：目录树、图片与富文本编辑、收藏、删除、全文搜索，以及「左侧原文 / 右侧渲染」可选分栏——**两侧都能直接编辑**；原文与渲染视图都支持输入 `/` / `、` 呼出**可选**格式块菜单（不选时字符保留），支持代码块多语言语法高亮、从文件管理器中打开、拖动移动条目、收起文件栏、拖动分割线调整分栏宽度、图片缩放、双端同步滚动与字符级双端光标提示。

## 入口

安装后刷新页面，左侧栏会多出一个笔记本图标（与「笔记」分组在同一列），点击即可打开主面板。面板 id 为 `markdown-notes`。

## 功能

- **目录结构**：任意层级文件夹；新建、重命名、删除、在任意文件夹内新建笔记。
- **文件中打开 / 拖动移动**：文件夹或笔记的右键菜单 / “...”菜单新增「从文件管理器中打开」，文件会在系统文件管理器中选中，文件夹会直接打开；按住节点拖到另一个非子级文件夹即可移动笔记或整个文件夹。
- **可收起文件栏**：面板左侧文件操作栏顶部有收起按钮，收起后主编辑区铺满；左上角保留一个展开按钮，再次点击恢复文件栏。收起状态会记忆。
- **笔记编辑**：
  - 左栏 `Markdown 原文`：等宽字体 textarea，Tab 缩进、Ctrl/Cmd+B/I/U 快捷键；
  - 右栏 `渲染视图`：contenteditable 的实时渲染结果，可直接点选、输入、加粗、列表、引用、链接、勾选任务项；
  - 顶部工具栏对当前聚焦的一侧生效；图片按钮或直接粘贴 / 拖入图片都可以。
  - **格式块菜单（飞书式，可选）**：在渲染视图的根级空段落 / 原文视图的空行里输入 `/` 或 `、` 会弹出格式块菜单；字符会正常写入文档，不选择格式时保留字符，继续输入或按 Esc 也保留。可用 ↑↓ 选择、Enter 插入、Esc 关闭，也可直接点击。支持正文、一/二/三级标题、无序 / 有序 / 待办列表、引用、代码块、表格、分割线；选中格式后会用对应的 Markdown 块替换触发字符，并自动把光标放到新块内。
  - **代码块语法高亮**：围栏代码块按 ` ```java ` / ` ```xml ` 等语言标记高亮关键字、类型、字符串、数字、注释、标签、属性、JSON key、diff 增删行等；支持 Java、JavaScript/TypeScript、Python、C/C++/C#、Go、Rust、Kotlin、Swift、PHP、Ruby、SQL、XML/HTML、CSS、JSON、YAML、Shell、PowerShell、Dockerfile、diff 等常用语言，未知语言按通用规则高亮且始终转义。
  - **代码块语言切换**：每个围栏代码块顶部显示当前语言下拉，未指定语言时显示 `text`；点击即可切换语言并立即改写 Markdown 围栏、重新高亮，代码内容保持不变。
  - 渲染视图里点击图片会显示缩放手柄：拖动右侧 / 底部 / 右下角等比调整尺寸，双击图片恢复原始大小；尺寸以 `{width=320}` 追加在图片语法后，原文与渲染结果始终同步。
- **可选分栏**：`分栏 / 原文 / 预览` 三档视图，选择会记忆。
- **可拖动分栏**：分栏视图中间有可拖动分割线，拖动即可调整左侧原文与右侧预览的宽度（每侧最小约 220px）；双击恢复 50/50，聚焦分割线后可用左右方向键微调，比例会记忆。窗口较窄时自动切换为上下布局并隐藏分割线。
- **同步滚动**：分栏模式下，标题栏右侧的「同步滚动」开关会把两侧滚动按内容块位置联动（优先对齐同一段内容，而不是简单按总高度百分比）；切换笔记或从单栏切回分栏时会自动对齐一次，开关状态会记忆。
- **双端光标提示**：分栏模式下，哪一侧正在编辑，另一侧就用同款闪烁光标标出对应内容位置。原文侧通过隐藏 mirror 精确测量 textarea 光标坐标；渲染侧通过 `data-line` 内容块、源码字符骨架与渲染文本的逐字符对齐来定位：**除 Markdown 格式标记外的正文/链接文字/代码/列表/引用/表格单元格字符都会精确落到对应字符**，不再只按行或百分比估算。
- **收藏**：笔记行悬停星标、编辑器标题栏星标，收藏会出现在目录树顶部「收藏」区。
- **删除**：笔记或整个文件夹删除前有确认对话框；删除即从磁盘移除。
- **搜索**：输入框按文件名即时过滤；按回车调用 Host 全文搜索（文件名 + 正文，带片段）。
- **自动保存**：停止输入约 0.9 秒后自动保存，Ctrl/Cmd+S 立即保存；标题栏显示保存状态。
- **存储设置**：面板内齿轮 / 左下角路径打开设置，可输入绝对路径，或使用宿主目录选择器；目录不存在会自动创建。

## 存储

- 默认目录：`<用户文档>/DSH Markdown Notes`
- 可在设置中切换；运行时设置保存在 `<profile 或 ~/.dsh>/markdown-notes/config.json`
- 每篇笔记就是普通 `.md` 文件，可用任何编辑器 / 同步盘管理
- 图片保存在根目录 `assets/YYYY-MM/`，Markdown 中使用相对路径（如 `![图](assets/2026-11/xxx.png)`），由面板的媒体接口提供渲染
- 收藏与「最近打开」保存在根目录 `.dsh-notes-meta.json`，随目录一起移动
- 目录树隐藏点文件、`assets/` 与 `node_modules/`

## Agent 工具

插件同时注册了 `markdown_notes` 工具，与面板共用同一仓库：

| action | 说明 |
| --- | --- |
| `list` | 目录树、收藏与统计 |
| `read` | 读取笔记（path） |
| `create` | 在 dir 下新建笔记（title） |
| `append` / `write` | 追加 / 覆盖笔记内容 |
| `mkdir` | 新建文件夹 |
| `search` | 全文搜索 |
| `favorite` | 收藏 / 取消收藏 |
| `delete` | 删除笔记或文件夹 |
| `set_storage` | 切换存储目录（绝对路径） |

删除与改写前请先 `read` 确认；除用户明确要求外不要删除笔记。

## 安全与边界

- 所有来自浏览器的路径都经过「相对路径规范化 + 根目录包含校验」，拒绝 `..`、绝对路径注入与符号链接删除。
- 图片按魔数识别，只接受 PNG / JPEG / GIF / WebP / BMP（拒绝 SVG 等可携带脚本的格式），单张上限 20 MiB。
- 写接口只接受同源 JSON 请求；`javascript:`、`vbscript:`、`file:` 与 `data:`（图片除外）链接会被降级。
- 渲染视图的「富文本 → Markdown」覆盖常用语法（标题、段落、粗斜体、删除线、高亮、下划线、代码、引用、列表 / 任务列表、链接、图片、表格、分隔线）；手工写的 Markdown 原样保留。

## 开发

```powershell
cd markdown-notes
node build.mjs          # 由 src/client/*.js 生成 client.js
node build.mjs --check  # 校验产物是否与源码同步
node tests/markdown.test.mjs
node tests/storage.test.mjs
node tests/client-render.test.mjs
node tests/client-boot.test.mjs
```

- Host 半侧：`index.js` + `host/`（ESM，零宿主包依赖）
- Client 半侧：`src/client/*.js` 按文件名拼接，`00-header.js` 必须第一、`99-apply.js` 必须最后
- 安装：`plugin_manager` → `install_bundle`，target 为本目录
